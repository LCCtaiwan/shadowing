# シャドー日本語

用長篇連續劇每天練日語聽力與跟讀（shadowing）的手機網頁 App，目標：旅行聽得懂、看日劇／動漫聽得懂、一年內 JLPT N3～N2。

- 劇本：Claude 原創撰寫（旅行日劇《終電のあとで》、動漫《放課後ラジオ部》）與 JLPT 形式聽解練習
- 配音：Google Gemini TTS（`tools/voice.py`，GitHub Actions 每天自動配音）
- 複習：Anki 式 FSRS 排程（句子、單字、片語、文法）
- 不使用市售教材或 JLPT 真題內容
