# 日語跟讀 App（先做日語，英語第二期）

## Context
使用者想每天用 shadowing 練聽力，目標是「旅行時聽得懂、看日劇／動漫聽得懂」。
已確認：
- 手機為主；日語會五十音；每天約 20–30 分鐘。
- **先做日語模式**，英語之後再加（架構先保留多語言）。
- 課程由 **Claude 撰寫**（先做第一批，之後每週在雲端排程持續更新），**Gemini API 只負責配音**。
- 長時間跟聽讀 → 長篇連續劇；日語有兩種類型：**旅行日劇** 與 **動漫**。
- 文法、片語、單字、句子都用 **Anki 式**複習。
- UI/UX 要好看好用、不套主題包裝；日語主題色朱紅，英語（第二期）青綠。

## 架構
```
Claude 雲端例行工作（每週日 20:00）
  └ 讀 story bible、課表、lexicon、上週回饋 → 寫下週劇本 JSON → 驗證 → push
GitHub Actions（每天 03:00，或 scripts/ 有新檔時）
  └ voice.py：隔天要用的劇本逐句送 Gemini TTS → ffmpeg 轉 mp3 → commit → GitHub Pages
手機 PWA（加到主畫面）
  └ 下載當天集數與音檔（service worker 快取，可離線）
  └ 跟讀、Anki 式複習、進度存 IndexedDB；可匯出/匯入備份
```
- Gemini 金鑰放 GitHub Secrets；手機與網頁不含金鑰。
- 每天只配隔天集數，分散 TTS 呼叫（實作時確認免費額度，必要時改付費層）。
- 永遠「領先一週」；例行工作某次失敗也不斷課。
- 回饋：每集結束點「太簡單／剛好／太難」，每週按「送出本週回饋」→ 預填好的 GitHub issue，Claude 下次寫課時讀取調整。

## 兩種類型（兩部連續劇）
每部有固定角色與聲音（`story/ja/<series>/cast.json` 指定 Gemini 聲音與語氣提示）。

### 旅行日劇《終電のあとで》（末班車之後）
台灣工程師 **林宇翔**（26）辭職後到日本自助旅行，在東京錯過末班車那晚認識一間咖啡店，後來回來打工度假。
- 階段 1：成田入境、Suica、飯店、便利商店、拉麵券売機、渋谷迷路
- 階段 2：浅草、藥妝店、居酒屋、錯過末班車、新幹線到京都、旅館女將敬語
- 階段 3：下北沢咖啡店打工：店長 **佐藤さん**（敬語／常體切換）、同事 **美咲**（～じゃん、～ちゃう）
- 階段 4：咖啡店面臨收店、大阪朋友 **健太**（關西腔）、告別與決定

### 動漫《放課後ラジオ部》（放學後廣播社）
台灣交換學生 **小雨**（17）轉進東京一所高中，被拉進快廢社的廣播社。社員各是典型動漫角色，每集後段是他們錄的**廣播劇**，輪流換類型（奇幻、推理、戀愛、熱血運動），一部劇就能聽到各種動漫說話方式。
- **陽太**：熱血男主，俺、～ぜ、～だろ，說話快
- **凛**：社長、傲嬌，～じゃない、べ、別に、～なさい
- **ひな**：天然學妹，丁寧語＋語尾拉長
- **黒川先生**：懶散顧問老師，大人常體
- 階段 1：清楚語速；自我介紹、社團、校園日常；廣播劇用簡單台詞
- 階段 2：快速鬥嘴、角色語（俺／僕／わたし、～ぜ／～わ／～じゃ）、擬聲擬態語
- 階段 3：情緒場面、喊叫、省略句、動漫常見口頭禪（やばい、マジで、うそでしょ）
- 階段 4：長廣播劇篇章（奇幻冒險、推理）、快語速多人對話

### 每週節奏
週一、三、五：日劇；週二、四、六：動漫；週日：本週總複習。
想多練時，兩部都可以當天看（App 會顯示另一部的最新集）。

## 每日流程（約 20–30 分，可分段、中斷可續）
1. 前情提要（30 秒，日語＋中文）
2. 盲聽整集（約 4 分）＋理解題
3. 逐場景：逐句懂（原文／假名／中文／片語）→ 看字跟讀，每句播 2 次，自動停頓 = 句長 ×1.3（約 10 分）
4. 盲跟讀整集（約 5 分）
5. 收卡：本集句子、單字、片語、文法加入牌組
6. Anki 式複習（約 8–10 分）

## 日語顯示
- 每句附假名標注 `ruby: [{t:"予約", r:"よやく"}, {t:"を"}...]`，用 `<ruby>` 呈現。
- 切換：漢字＋假名／只假名／隱藏文字。不提供羅馬拼音。
- 每集一個文法或口語重點（中文說明）；動漫集另標「角色語」說明（例：～ぜ 是男性、強勢語氣）。

## UI / UX
視覺：米白底、深墨字、大字級、大留白、圓角卡片；深色模式與字級調整。
- 主題色以 CSS 變數 `--brand / --brand-strong / --brand-tint` 實作，`<body data-lang>` 切換。日語：朱紅 `#993C1D`／`#D85A30`／`#FAECE7`；英語（第二期）：青綠 `#0F6E56`／`#1D9E75`／`#E1F5EE`。
- 兩種類型用小標籤區分：日劇（朱紅）、動漫（紫 `#534AB7`／`#EEEDFE`），主題色不變。
- 介面按鈕用日文（例：復習を始める），說明文字用中文。
- **首頁**：今日總時間＋進度環；今日任務（今天的集數＋複習），完成就劃掉；一週打卡；「繼續：下一步」。
- **跟讀播放器**：步驟進度條；大字原文＋假名、重點字底色；中文預設模糊點開才看；「換你念」倒數環；控制鍵在拇指區（0.75×／1×、上一句、重播、下一句、更多）。
- **牌組總覽**：句子聽力／單字／片語／文法，各顯示新、學習中、到期與預估分鐘數。
- **複習卡**：依類型呈現；「重來／困難／良好／簡單」按鈕顯示下次時間。
- **完成頁**：練了幾句、跟讀幾次、明天到期幾張；本集難度三選一。
- 課程庫（依類型與集數重聽、收藏句子）、統計、設定。
- UX：一鍵串接流程；中斷可續；Wake Lock；鎖屏／耳機線控（Media Session）；主要按鈕在下半部、點擊區 ≥ 44pt；尚未配音或離線時清楚提示並建議改做複習或重聽舊集。
- 選做：錄自己的聲音與原音對照。
- 實作前先做**可在手機點的高擬真原型**（Artifact），確認後再寫正式程式。

## Anki 式複習
**牌組**：`日本語 ›` 句子聽力、單字、片語、文法（含動漫角色語）。兩部劇共用牌組，卡片標示出自哪部哪集。

| 類型 | 正面 | 背面 |
|---|---|---|
| 句子・聽力 | 只播音檔 | 原文＋假名＋中文＋片語 |
| 單字・聽音辨義 | 播單字音檔 | 漢字＋讀音、詞性、中文、劇中例句（有音檔） |
| 單字・看字讀音 | 漢字 | 讀音＋意思＋例句 |
| 片語・填空聽力 | 播整句，片語挖空 | 片語、中文、出處 |
| 文法・例句理解 | 劇中例句（有音檔），標出句型 | 句型、中文說明、另 2 例句 |
| 文法・填空（選做） | 新例句挖掉句型 | 正確形式＋說明 |

- 以聽懂、認得為主；「中文 → 說日語」產出卡預設關閉。
- 排程：FSRS（Anki 現行預設，`ts-fsrs` 放進 `app/vendor/`）；學習步驟 1 分 → 10 分；目標記憶率 90%。
- 每日上限：新卡 15、複習 80；順序：學習中 → 到期 → 新卡，子牌組交錯。
- 卡片瀏覽器：搜尋、暫停、標記；連續忘 8 次標為頑固卡；兄弟卡同日不同時出現。
- Claude 寫課配套：每集附 `vocab`（8–10）、`phrases`（4–6）、`grammar`（1，附 2 例句），全部連回劇中句子 id；維護 `lexicon.json`（兩部劇共用）避免重複新教、後面集數刻意再用（螺旋複習）；卡片 id 由內容產生（例：`ja:vocab:終電`）。

  "scenes": [{ "id": "s1", "setting": "...", "lines": [

  "questions": [{"q": "...", "options": ["..."], "answer": 0}] }

## 實作步驟
1. 移到正式資料夾（建議 `~/Desktop/shadowing`），git init，建 `docs/develog.md`。
2. 高擬真互動原型（Artifact，日語、兩種類型），iPhone 試用確認。
3. 第一批內容：兩部劇 bible、cast、lexicon、`plan.json`、階段 1 大綱、第 1–2 週劇本（各 6 集）；`validate.py`。
4. `voice.py`：用使用者的 Gemini 金鑰本機先配日劇第 1 集、動漫第 1 集，確認日語發音、語速、動漫角色語氣。
5. 手機 PWA：依原型實作首頁、跟讀流程、播放器、假名切換、收卡、完成頁、設定。
6. `cards.js` ＋ `srs.js`（FSRS、每日上限、學習步驟）＋ 牌組總覽、卡片瀏覽器；單元測試。
7. 建 GitHub repo（先問；免費 Pages 需公開，內容只有劇本與音檔）、設 Secret、開 Pages、加 `voice.yml`，手動觸發一次。
8. 用 `schedule` skill 建 Claude 每週例行工作（寫下週劇本 → 驗證 → push），先手動跑一次。
9. iPhone 加主畫面實測一週並微調。
10. 第二期：英語《Open Return》（青綠主題，架構已支援）。

## Verification
- `node --test tests/`：卡片產生（各類型、id 穩定、兄弟卡）、排程（學習步驟、每日上限、四種評分下次時間）。
- `python3 -m pytest tools/`：劇本 schema、vocab／phrases／grammar 都連得到句子、ruby 與原文一致。
- 本機 `python3 -m http.server`，內建瀏覽器手機尺寸走完：日劇與動漫各一集 → 假名三模式 → 收卡 → 四種卡片複習 → 完成頁回饋；調整時間確認到期卡出現。
- Actions 手動觸發後 Pages 出現隔天音檔；例行工作手動執行後出現下週劇本且通過驗證。
- iPhone 加主畫面：鎖屏線控、離線播放已下載集數。
