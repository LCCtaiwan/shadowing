# 劇本撰寫規格（Claude 寫課用）

本文件給撰寫劇本的 Claude（本機或每週雲端例行工作）使用。寫完一律執行：

```bash
python3 tools/validate.py
.venv/bin/python tools/check_readings.py   # 用斷詞器比對假名讀音
```

## 共通原則
- **全部原創**。不得抄錄或改寫市售教材、JLPT 真題、公式問題集、動漫或日劇台詞。
- 中文一律用**台灣繁體中文**與台灣慣用語（例：計程車、便當、捷運、悠遊卡）。
- 日語要自然、像真人會說的話；店員、站員用真實的接客用語。
- 程度控制：只用本集 `level` 以下的文法；生詞（高於目前級別的詞）不超過全集詞數的 5%，非用不可時列入 `vocab` 並在中文註明。
- 每集要**重用**前幾集教過的單字與文法（螺旋複習），重用的單字若再列入 `vocab` 要加 `"review": true`。
- 角色說話方式依 `story/ja/<series>/bible.md` 與 `cast.json`，前後一致。

## 假名（ruby）規則
- `ruby` 是片段陣列：`["假名或標點"]` 或 `["漢字", "讀音"]`。所有片段的第一個元素依序接起來必須**完全等於** `text`。
- 讀音只標在漢字部分，送り仮名放在片段外：`["温", "あたた"], ["めますか？"]`。
- 熟語整個標：`["大丈夫", "だいじょうぶ"]`；數字＋量詞整串標讀音（含音便）：`["六百八十円", "ろっぴゃくはちじゅうえん"]`。
- 用阿拉伯數字時一樣要標讀音：`["3", "さん"], ["番線", "ばんせん"]`；英文字母或品牌照樣標：`["Suica", "スイカ"]`。
- 讀音全部用平假名（外來語的片假名照原樣）。特殊讀音（今日、一人、二十歳）照實際唸法。

## 劇本 JSON（`scripts/ja/<series>/wNN/eNN.json`）
```json
{
  "id": "ja-drama-w01-e01",
  "lang": "ja", "series": "drama", "week": 1, "episode": 1, "level": "N5",
  "title": "成田空港・入国審査", "title_zh": "成田機場・入境審查",
  "recap": { "text": "…", "ruby": [["…"]], "zh": "…" },
  "focus": { "title": "聽力重點標題", "zh": "這集要特別注意聽什麼（1–2 句）" },
  "scenes": [
    { "id": "s1", "kind": "scene", "setting_zh": "成田機場入境櫃台",
      "lines": [
        { "id": "s1-01", "speaker": "officer", "text": "パスポートを見せてください。",
          "ruby": [["パスポートを"], ["見", "み"], ["せてください。"]],
          "zh": "請出示護照。", "focus": ["見せてください"], "style": "事務的、ゆっくり" }
      ] }
  ],
  "vocab": [ { "id": "ja:vocab:入国", "text": "入国", "reading": "にゅうこく", "pos": "名詞", "zh": "入境", "level": "N3", "line": "s1-02", "surface": "入国" } ],
  "phrases": [ { "id": "ja:phrase:見せてください", "text": "見せてください", "surface": "見せてください", "zh": "請給我看", "line": "s1-01" } ],
  "grammar": [
    { "id": "ja:grammar:te-kudasai", "pattern": "〜てください", "zh": "請～（請求、指示）", "level": "N5",
      "line": "s1-01", "surface": "見せてください",
      "examples": [ { "text": "…", "ruby": [["…"]], "zh": "…" }, { "text": "…", "ruby": [["…"]], "zh": "…" } ] }
  ],
  "questions": [ { "q": "日語問題", "q_zh": "中文問題", "options": ["…", "…", "…"], "answer": 1 } ]
}
```

欄位說明：
- `recap`：前情提要，日語 1–2 句（本集程度），第 1 集寫故事開場。
- `scenes`：2–3 個；動漫從第 3 集起最後一場可為 `"kind": "radio"`（廣播劇）。每集合計 **18–30 句**。
- `speaker`：必須是 `story/ja/**/cast.json` 裡的 id。旁白用 `narrator`。
- `focus`（句子內）：本集重點字句，必須是 `text` 的子字串；全集約 4–8 處。
- `style`（選填）：給 TTS 的語氣提示，例：「慌てて、早口」「棒読みっぽく」「魔王らしく低く」。
- `card`（選填，預設 true）：此句是否做成句子聽力卡；寒暄重複的句子可設 false。
- `vocab`：約 15–20 個；`text` 用辭書形；`surface`（選填）是句中實際出現的形式；`level` 用 N5–N1 估計。
- `phrases`：4–6 個實用片語；`surface` 必須是句中子字串（做填空卡）。
- `grammar`：**正好 2 個**，依 `curriculum/plan.json` 指定；`surface` 是句中體現該文法的部分；另附 2 個新例句（不可與劇中句子相同）。
- `questions`：2 題理解題（盲聽後作答），3 個選項，日語出題，附中文。

ID 慣例：`ja:vocab:<辭書形>`、`ja:phrase:<片語>`、`ja:grammar:<羅馬字-連字號>`（例：`te-kudasai`、`kara-riyuu`、`ni-narimasu`）。同一個詞或文法在不同集要用同一個 id。

## 聽解ドリル JSON（`scripts/ja/drill/wNN/dN.json`，週日模擬為 `sun.json`）
每天（d1–d6）：**即時応答 6 題＋其他題型 2 題**（N5/N4 期用 課題理解、ポイント理解、発話表現 輪替）。週日 `sun.json`：即時応答 6、課題理解 2、ポイント理解 2、発話表現 2，共 12 題。

```json
{
  "id": "ja-drill-w01-d1", "lang": "ja", "week": 1, "day": 1, "level": "N5",
  "items": [
    { "id": "w01d1-01", "type": "sokuji",
      "script": [ { "speaker": "woman", "text": "…", "ruby": [["…"]], "zh": "…" } ],
      "options": [ { "text": "…", "ruby": [["…"]], "zh": "…" }, { … }, { … } ],
      "answer": 0, "explain_zh": "為什麼是這個答案、其他選項錯在哪" },
    { "id": "w01d1-07", "type": "kadai",
      "setup": { "text": "男の人と女の人が話しています。男の人はこれから何をしますか。", "ruby": [["…"]], "zh": "…" },
      "question": { "text": "男の人はこれから何をしますか。", "ruby": [["…"]], "zh": "…" },
      "script": [ …4–10 句對話… ],
      "options": [ …4 個… ], "answer": 2, "explain_zh": "…" },
    { "id": "w01d1-08", "type": "hatsuwa", "situation_zh": "你在餐廳想加點水。你要說什麼？",
      "script": [ { "speaker": "narrator", "text": "レストランで水がほしいです。何と言いますか。", "ruby": [["…"]], "zh": "…" } ],
      "options": [ …3 個… ], "answer": 1, "explain_zh": "…" }
  ]
}
```

題型規則（模仿 JLPT 形式，內容原創）：
- `sokuji` 即時応答：一句話＋3 個回應，選項只用聽的。錯誤選項要有「聽起來像但不對」的陷阱（授受方向、時態、肯否混淆、敬語誤用）。
- `kadai` 課題理解：先唸 setup（含問題），再播對話，最後再唸一次 question；4 個選項（印在畫面上）。問「接下來要做什麼／先做什麼」。
- `point` ポイント理解：同上，但問理由、細節（為什麼、哪一個、幾點）。
- `hatsuwa` 発話表現：以 `situation_zh` 描述情境（取代插圖），narrator 唸日語情境句；3 個選項是「這時該說的話」。
- `gaiyo`／`togo`：N3、N2 期才用。
- 對話角色可用 `man`、`woman`、`narrator`，也可用兩部劇的角色（熟悉的聲音）。
- 題目主題配合當週劇集情境與文法，讓學到的東西馬上被考到。

## 單字連結（神經元連結卡用）
每個 `vocab` 可加 `links`，讓卡片背面畫出連結圖、並產生「連結題」：

```json
"links": {
  "collocations": [ { "cue": "レンジで", "text": "レンジで温める", "zh": "用微波爐加熱" } ],
  "opposite": [ { "text": "冷やす", "reading": "ひやす", "zh": "弄涼、冰鎮" } ],
  "related": [ { "text": "温度", "reading": "おんど", "zh": "溫度" } ]
}
```
- `collocations`：1–2 個最常見、最實用的搭配（旅行、家庭、動漫會用到的優先）。`text` 必須以 `cue` 開頭，`text` 去掉 `cue` 後就是這個單字的形式（通常是辭書形，也可以是常用活用形）；`cue` 要能讓人推出答案，但不能只有一個字。名詞可用「〜を」「〜に」前後搭配（例：cue「荷物を」→「荷物を預ける」是「預ける」的搭配；放在「荷物」上就用 cue「重い」→「重い荷物」）。
- `opposite`：有自然的反義或對比才加（大きい↔小さい、乗る↔降りる）；沒有就省略。
- `related`：0–2 個語意相關、同場景常一起出現的詞（優先選 `story/ja/lexicon.json` 已有的詞）。
- 「同漢字」的連結 App 會自動從 lexicon 算出來，不用寫。
- 日文一律新字體；讀音全平假名（外來語片假名）；中文用台灣繁體。

## 廣播聽力包（`scripts/ja/announce/aNN.json`）
車站、新幹線、機場、商場／遊樂園、延誤與天氣、緊急（地震、避難、尋人）的廣播。每份 8 題，格式同聽解ドリル的 `point`／`kadai`／`gaiyo`，另加：
```json
{ "id": "ja-announce-a01", "lang": "ja", "kind": "announce", "level": "N4", "title": "駅のアナウンス", "title_zh": "車站廣播", "tip_zh": "聽廣播的訣竅",
  "items": [ { "id": "a01-01", "type": "point", "situation_zh": "你在東京站 5 號月台等車", "setup": {…}, "question": {…},
               "script": [ { "speaker": "announcer_f", "text": "…", "ruby": […], "zh": "…" } ], "options": [ 4 個 ], "answer": 0, "explain_zh": "…" } ] }
```
- 廣播稿要像真的日本廣播（「まもなく」「〜番線に〜行きがまいります」「黄色い線の内側までお下がりください」「ただいま〜の影響で」），內容原創，不抄錄任何鐵路公司或機場的實際廣播。
- 每段廣播 2–5 句；`script` 用 `announcer_f`／`announcer_m`（車內、機場）或 `staff_f` 等；setup/question 由 `narrator` 唸。
- 題目考旅行時真正需要的資訊：幾號月台、幾點、延誤原因、要不要換車、集合地點、要做什麼。

## 親子一起學（series `kids`，`scripts/ja/kids/wNN/eNN.json`）
給要去日本的小孩（約 5–10 歲）和陪同大人：每話一個小孩會遇到的場面，台詞短、可愛、實用。
- 格式同劇本，但每集 **12–18 句**；角色用 小米 `xiaomi`、阿寶 `abao`、そうた `sota`、中村さん `nakamura`、店員等。
- 小孩台詞用最簡單的日語（丁寧語或常體都可，但要真實），重點片語是小孩能自己說出口的話（「これください」「トイレはどこですか」「いっしょにあそぼう」）。
- `grammar` 仍需 2 個，但選最基本的句型（〜ください、〜はどこですか、〜たい、〜ましょう、〜ね／〜よ…）。
- `vocab` 10–15 個，附 `links`；`focus` 標小孩要會說的句子。

## 日本童話原文（series `tales`，`scripts/ja/tales/w01/eNN.json`）
楠山正雄的公有領域版本（來源 `story/ja/tales/source.json`，`{漢字|よみ}` 是青空文庫原有的假名）。
- **原文一字不改**：只能把段落切成句子（以「。」或閉合的「」」為界，太長的句子可在「、」處再切），去掉行首的全形空白；不可改字、不可改寫、不可加字。所有 `text` 依序接起來必須等於原文（去掉空白與換行）。
- 所有句子 `speaker` 都是 `storyteller`。對話句可加 `style`（例：「鬼の声で、太く」「おばあさんの声で、やさしく」）。
- `ruby`：青空文庫已有的讀音照用；其他漢字補上正確讀音（依上下文、古風讀法也照原文）。
- 每話（一章，或過長的章拆成兩話）**20–45 句**；`episode` 編號：桃太郎 11–、浦島太郎 21–、一寸法師 31–、花咲かじじい 41–、舌切りすずめ 51–、金太郎 61–（依章節順序遞增）。
- 加 `source`：`{"title": "桃太郎", "author": "楠山正雄", "via": "青空文庫", "card": "https://www.aozora.gr.jp/cards/000329/card18376.html", "part": 1}`。
- `recap`：第一話寫故事開頭一句（可直接引用原文第一句），之後寫前情提要（這句可以是自己寫的簡單日語）。
- `vocab` 10–20（附 `links`，古語或現代少用的詞在中文註明「古風」）；`phrases` 3–6；`grammar` 0–2（可選古風句型，例：〜ものですから、〜とみえて）；`questions` 2。
- `level`：依難度標 N4 或 N3。

## JLPT 單字庫（`data/jlpt/nN.json`）
由 `data/jlpt/raw-nN.json` 補完，每筆：
```json
{ "id": "ja:vocab:会う", "text": "会う", "reading": "あう", "level": "N5", "en": "to meet, to see",
  "zh": "見面、遇見", "pos": "動詞",
  "example": { "text": "駅で友だちに会います。", "ruby": [["駅", "えき"], ["で"], ["友", "とも"], ["だちに"], ["会", "あ"], ["います。"]], "zh": "在車站和朋友見面。" },
  "links": { "collocations": [ { "cue": "友だちに", "text": "友だちに会う", "zh": "和朋友見面" } ], "opposite": [ { "text": "別れる", "reading": "わかれる", "zh": "分開" } ], "related": [] } }
```
- `id`、`text`、`reading`、`level`、`en` 照 raw 不改（raw 的讀音若明顯有誤，寫在 `note_zh` 說明，不要改 id）。
- `zh`：台灣繁體、簡短（2–3 個意思以內）；`pos`：名詞／動詞／い形容詞／な形容詞／副詞／連體詞／接續詞／感動詞／助数詞／代名詞／表現。
- `example`：原創、自然、短（N5–N4 約 8–18 字），只用該級以下的詞；情境優先旅行、家庭、日常、動漫；必須用到該單字（可活用）。
- `links`：同劇本規則；至少 1 個搭配（真的不適合時可空，但盡量給）。

### 台灣用語對照（所有 `zh` 欄位）
用台灣說法，不用大陸說法：計程車（不是出租車）、捷運（地鐵）、公車（公交車）、機車（摩托車）、腳踏車（自行車）、便當（盒飯）、冷氣（空調）、悠遊卡（交通卡）、手機（手機）、網路（網絡）、軟體（軟件）、資訊（信息）、影片（視頻）、品質（質量）、計程車司機、超商／便利商店（便利店）、垃圾桶、行李箱、馬鈴薯（土豆）、鳳梨（菠蘿）、優格（酸奶）、早餐店、補習班、健保、身分證、加油（打氣）。
